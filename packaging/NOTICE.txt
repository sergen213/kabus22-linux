Kabus22 native installer packaging notice

The packager tools/package_kabus_appimage.py assembles a genuine x86-64 Type-2
ELF AppImage with a SquashFS payload. It does not build the engine, execute any
Windows game/setup program, or include original game data, scripts, proprietary
SDKs, mod archives or game artwork. The generic SVG icon is packaging artwork;
the installer obtains original game artwork only from user-supplied media.

Current-source original-campaign widescreen correction (v0.1.1 release target):
  The native engine, not installer flags or copied WDL, owns the default for
  an automatically selected, recognized original K22.wdl campaign. ISO-only
  installation includes recovered resolution and state-dependent menu/HUD/text
  geometry with original media artwork, including its illustration/eye animation.
  No proprietary community-patch scripts, replacement artwork or Windows DLLs
  are redistributed. --patch remains an explicit choice for separately obtained
  extras; the installer neither discovers nor bundles a patch and does not
  rewrite the original scripts. Shortcuts retain bin/kabus22 --data game.
  OpenGL, Vulkan raster and Vulkan RT consume the same engine-prepared camera,
  UI and hit geometry. Authored signed ARC/ASPECT is retained; this is not an
  inferred Hor+ conversion, exact patch restyling or a Bonus widescreen algorithm.
  Already-patched K22Widescreen.wdl and custom --script behavior are unchanged.

  Ghidra-recovered indexed PCX FONT semantics retain indices and use the
  normalized active RGB palette, not the embedded PCX palette or index-as-alpha.
  Palette selection is inputbasename.raw, then palette.raw, then RGB332 fallback;
  index 0 is black, index 255 white, and dark nonzero entries are lifted to 8.
  World palette events refresh cached FONT images; ordinary BMAP embedded-palette
  decoding is unchanged. Fonts and patch assets are not redistributed: user media
  supplies the game fonts. All eight genuine original Font0 load-menu rows have
  OpenGL/Vulkan raster/RT glyph-pixel evidence at the WM-clamped 2560x1377 window,
